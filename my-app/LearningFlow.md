# Learning flow

This file is the source of truth for the conceptual path a learner takes through Webrew: the first visit, the gated curriculum, and ideas for later levels. It records intent, not implementation.

[AGENTS.md](AGENTS.md) stays the source of truth for the tech stack, interface language and direction, how current features behave, and working agreements.

The curriculum does not rewrite Alephbet, flashcards, training, streaks, or auth. Those stay available as they are, although they will be blocked for beginners less than level 3. Curriculum levels (0L, 1, 2) are a content gate. Content is by design fed gradually to the user so flashcards and aleph bet will be unlocked at level 3, training will be unlocked at level 10.

## Scope

Hebrew from scratch. A learner sees only content for their current curriculum level until they pass it. Content above that level stays locked.

Passing a level means completing that level's required set at the accuracy named below. A failed attempt can be retaken. A fail does not trap the learner on Level 0.3, Level 1, or Level 2.

The "already know some Hebrew" assessment, and every level after 2, come later and are not specified here.

## Start

On a first visit, the home entry offers two actions:

- **Absolute beginner? Start here** — opens Level 0L.
- **Already know some Hebrew? Take an assessment to skip levels** — a placeholder until that assessment exists.

## Level 0L

A guided introduction. The learner moves forward only by pressing Next. The screens are labelled like a game level:

- **1.0** — the alphabet introduction
- **1.1** — all 22 letters. Each one says ah (patach). The mark stays hidden.
- **1.2** — the first five letters. Clicking a letter changes its nikud and plays the new sound.
- **1.3** — all 22 letters with the patach mark visible
- **1.4** — a listening quiz. Each sound offers three letter cards.

### 0.1 Alphabet

The Hebrew alphabet has 22 letters, each with its own consonant sound. The letters appear on the screen. Hovering a letter plays that consonant.

Next focuses the first five letters and centers them. The screen explains that nikud changes the vowel a letter produces. Five nikud types then animate onto those letters. Letters stay black. Nikud is blue, so the vowel marks stay easy to see.

### 0.2 One letter, many vowels

Next focuses on ד. Each vowel from the set below appears on its own card. Pressing a card plays that syllable: dah, deh, d (consonant only), dee, doo, doh.

### 0.3 Ah on every letter

Next opens a voice check. Each letter is shown with only the "ah" vowel: dah, bah, khah, and the rest of the alphabet. Passing every letter unlocks Level 1.

## Vowel set

From 0.2 onward, practice uses this set. It is the curriculum vowel set. It does not change the existing nikud deck.

| Nikud | Sound |
| --- | --- |
| kamatz, patach | ah |
| tsere, segol | eh |
| shva | no vowel, consonant only |
| hiriq | ee |
| kubutz, shuruk | oo |
| holam, with and without ו | oh |

## Level 1

The learner knows the letters and practices the aleph-bet as flashcards, limited to the vowel set above. Passing requires 85% accuracy on both the letters and the nikud. That pass unlocks Level 2.

## Level 2

The learner forms and reads basic pointed Hebrew: one-syllable words. The Level 2 word set starts with גג, דג, עץ, שם, פה, and את. The rest of that list is still to be completed, and should not be invented here.

For each word, the learner says it, or marks by hand whether they got it right. The full list must be practiced at 85% or better. Failed attempts can be retaken. Passing unlocks Level 3.
